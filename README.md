# Features:

- Apple pick: *Go and get those apples! All of them!*
- Waffle wham: *There's nothing that needs to be said here. Get those waffles!*
- Crabby catch: *Help Crabby catch that coconut.*
- Crazy carrots: *It's raining carrots! Be sure you don't get hit!*
- Last slice: *Stake your claim on the pizza! Don't miss!!*
- Tug of claw: *Wrestle and yank out that radish. Easy huh?*
- Munchy maze: *Yes, there are more apples to collect. Go get them!*
